# Open PO Cireng - GitHub Pages + Firebase

## Fitur
- Halaman publik daftar pesanan Open PO
- Panel admin dengan Firebase Authentication
- Tambah, edit, hapus pesanan
- Firebase Firestore
- Responsive

## Setup Firebase
1. Buat project di Firebase Console.
2. Tambahkan Web App.
3. Salin konfigurasi ke `firebase-config.js`.
4. Aktifkan Authentication > Email/Password.
5. Buat akun admin di Authentication > Users.
6. Aktifkan Firestore Database.
7. Buat rules Firestore yang sesuai.

## GitHub Pages
Upload seluruh isi folder ini ke repository GitHub.
Settings > Pages > Deploy from branch > main / root.
